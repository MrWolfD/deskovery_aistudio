# Развертывание Deskovery на Ubuntu 24.04 через GitHub

Пошаговое руководство по развертыванию вашей доски **Deskovery** с автоматическим бесплатным HTTPS (SSL) и WebSockets через GitHub и Docker.

---

## Этап 1. Экспорт проекта в ваш GitHub (1 минута)

1. В интерфейсе Google AI Studio в верхнем правом углу нажмите кнопку **Export** (или иконку GitHub).
2. Выберите **Export to GitHub**.
3. Создайте репозиторий под именем `deskovery` (он может быть публичным или приватным).
4. Весь проект автоматически загрузится в ваш GitHub.

---

## Этап 2. Запуск на сервере Ubuntu 24.04 (всего 5 команд)

Подключитесь к вашему VPS по SSH с локального компьютера:
```bash
ssh root@IP_ВАШЕГО_СЕРВЕРА
```

### Команда 1. Установка Docker и Git
```bash
apt update && apt install -y git curl && curl -fsSL https://get.docker.com | sh
```

### Команда 2. Клонирование репозитория с GitHub
*(Замените `ВАШ_АККАУНТ` на ваш логин на GitHub)*:
```bash
git clone https://github.com/ВАШ_АККАУНТ/deskovery.git /opt/deskovery
cd /opt/deskovery
```
> *Если ваш репозиторий приватный, GitHub попросит ввести логин и Personal Access Token (PAT).*

### Команда 3. Указание вашего сабдомена
*(Замените `deskovery.duckdns.org` на ваш точный сабдомен)*:
```bash
echo "DOMAIN=deskovery.duckdns.org" > .env
```

### Команда 4. Сборка и запуск контейнеров
```bash
docker compose up -d --build
```

**Всё готово!** 🚀
* Веб-сервер **Caddy** автоматически получит бесплатный SSL-сертификат от Let's Encrypt за 10-15 секунд.
* Открывайте в браузере: `https://deskovery.duckdns.org` (с зеленым замочком HTTPS 🔒).

---

## Этап 3. Как обновлять проект в будущем

Когда вы внесете новые изменения в код и сделаете коммит в GitHub, на сервере достаточно выполнить одну команду для мгновенного обновления:

```bash
cd /opt/deskovery && git pull && docker compose up -d --build
```
Доска пересоберется в фоне без потери сохраненных данных.

---

## 🛠 Полезные команды на сервере

* **Просмотр логов в реальном времени:**
  ```bash
  cd /opt/deskovery && docker compose logs -f
  ```
* **Перезапуск контейнеров:**
  ```bash
  cd /opt/deskovery && docker compose restart
  ```
* **Остановка приложения:**
  ```bash
  cd /opt/deskovery && docker compose down
  ```
* **Проверка статуса работы:**
  ```bash
  docker compose ps
  ```

## 🔒 Безопасность и Приватность в Deskovery

1. **Стартовая страница входа (Landing Gate):**
   * При открытии корня сайта `https://deskovery.duckdns.org` посетитель видит презентационную стартовую страницу с формой входа.
   * **Только члены команды, знающие командный пароль, могут войти в рабочее пространство, увидеть каталог имеющихся досок и создавать новые**.
   * Пароль задается в файле `.env` на сервере:
     ```env
     TEAM_PASSWORD=ваш_надежный_пароль_команды
     ```
     *(По умолчанию для удобства первого запуска: `deskovery2026`)*.
   * Сессия запоминается на устройстве (в шапке каталога есть кнопка **«Выйти»**).

2. **Защита каталога и комнат на сервере:**
   * Список досок и создание новых комнат защищены на уровне REST API: без токена команды сервер вернет `401 Unauthorized`.
   * Брутфорс-защита (Rate Limiting): после 5 неудачных попыток ввода пароля IP временно блокируется на 2 минуты.

3. **Секретные ссылки-приглашения (1-click доступ для гостей/друзей):**
   * Если вам нужно показать доску заказчику или другу, не давая ему пароль от всего пространства компании:
     В шапке доски нажмите **«Поделиться»** и отправьте ссылку:
     `https://deskovery.duckdns.org/?room=название&invite=секретный_ключ`
   * Гость сразу попадет на конкретную доску, минуя каталог и не видя остальные проекты компании.
   * Ссылку можно в любой момент отозвать и перегенерировать кнопкой 🔄.

4. **Защита отдельных комнат:**
   * Внутри пространства команды можно дополнительно защитить отдельную доску персональным PIN-кодом.
   * В шапке всегда отображается статус комнаты: 🔒 «Защищена» или 🌐 «Открытая».

5. **Темная и светлая тема (Dark / Light Mode):**
   * В шапке доски и в каталоге комнат доступна кнопка переключения ☀️ / 🌙.
   * Система автоматически определяет системные настройки ОС и сохраняет выбор в браузере.
   * Адаптирован холст, сетка, стикеры, панели инструментов и модальные окна.
