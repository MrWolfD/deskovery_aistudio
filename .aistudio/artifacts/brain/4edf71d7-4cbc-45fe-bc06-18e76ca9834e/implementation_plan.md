# План: Страница выбора комнат (Лобби) и доступ по паролю

## Концепция
Полноценное пространство комнат Deskovery:
* Пользователь попадает на страницу со списком доступных комнат (или может открыть конкретную комнату по ссылке).
* Для каждой комнаты отображается статус: открытая (🌐) или защищенная паролем (🔒).
* Для входа в защищенную комнату требуется ввести пароль.
* Возможность создать новую комнату с паролем или без прямо из Лобби.
* Кнопка возврата к выбору комнат из шапки любой доски.

---

## Архитектура решения

### 1. Серверная часть (`server.ts`)
* **Реестр комнат**:
  * Каждая комната хранит: `id`, `title`, `description`, `password` (опционально), `createdAt`, `elements`, `clients`.
  * Начальные дефолтные комнаты для удобства (например, «Главная доска», «Командный спринт»).
* **REST API**:
  * `GET /api/rooms` — публичный список комнат (возвращает `id`, `title`, `description`, `hasPassword: boolean`, `userCount`, `updatedAt`). Секретные пароли наружу **никогда не утекают**.
  * `POST /api/rooms` — создание комнаты (название, описание, пароль).
  * `POST /api/rooms/:roomId/verify` — проверка пароля перед входом.
* **WebSocket**:
  * Проверка пароля при подключении к комнате. Если пароль неверный — доступ к данным блокируется.

### 2. Страница Лобби / Выбора комнат (`src/components/Lobby/LobbyPage.tsx`)
* **Стильный интерфейс Deskovery**:
  * Верхняя панель с брендом Deskovery, статусом сервера и кнопкой «+ Создать комнату».
  * Сетка карточек комнат с поиском и фильтром («Все», «Открытые», «Защищенные»).
  * Индикаторы:
    * 🔒 Защищена паролем
    * 👥 Онлайн-участники
    * 🕒 Последняя активность
  * Модальное окно **«Создание комнаты»**:
    * Название комнаты
    * Описание (опционально)
    * Тумблер «Защитить паролем» + поле ввода пароля.
  * Модальное окно **«Вход в комнату»**:
    * Запрос пароля при клике на защищенную комнату с валидацией и отображением ошибок.

### 3. Интеграция с доской (`src/App.tsx` и `TopHeader.tsx`)
* Режимы приложения:
  * `lobby` — отображается страница выбора комнат.
  * `board` — активная доска выбранной комнаты.
* В шапке доски:
  * Кнопка **«Все комнаты»** (с иконкой сетки/каталога) для быстрого возврата в Лобби.
  * Индикатор текущей комнаты и статуса защиты (🔒 / 🌐).
* Поддержка URL параметров:
  * При заходе на `deskovery.duckdns.org` → открывается Лобби.
  * При заходе с параметром `?room=название` → прямой переход в комнату (с запросом пароля, если она защищена).

## План проверки
1. Открытие главной страницы сайта → отображается каталог комнат.
2. Вход в открытую комнату → переход на интерактивную доску без пароля.
3. Возврат по кнопке «Все комнаты» обратно в Лобби.
4. Создание новой комнаты с паролем (например, PIN: `1234`).
5. Попытка входа с неверным паролем → отказ; с верным → успешный вход.
6. Открытие ссылки в режиме инкогнито → корректный запрос пароля перед показом данных.
